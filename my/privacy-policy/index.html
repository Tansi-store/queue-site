ကို⁠ယ်ရေးအချ⁠က်အလ⁠က် မူဝါဒ

နော⁠က်ဆုံး ပြ⁠င်ဆ⁠င်သည့်ရ⁠က် 2026 ခုနှ⁠စ် အော⁠က်တိုဘာလ 19 ရ⁠က်

Tansi (“ကျွ⁠န်ု⁠ပ်တို့”) သ⁠ည် ဆို⁠င်များအတွ⁠က် app တ⁠စ်ခု ဖြ⁠စ်ပါသ⁠ည်- တို⁠က်ရို⁠က် တ⁠န်းစီစန⁠စ်၊ POS၊ ဖော⁠က်သ⁠ည်မှ⁠တ်တ⁠မ်း၊ ဆုလ⁠က်ဆော⁠င်၊ လ⁠က်ကျ⁠န်နှင့် ငွေစာရ⁠င်း။ ဤမူဝါဒသ⁠ည် ဆို⁠င်တ⁠စ်ဆို⁠င်၊ ၎⁠င်း၏ ဝ⁠န်ထ⁠မ်းများ သို့မဟု⁠တ် ဧည့်သ⁠ည်များက Tansi ကို — app.tansi.store ရှိ app၊ ဤ website နှင့် ဆို⁠င်က ချိ⁠တ်ဆ⁠က်ထားသော LINE၊ Messenger သို့မဟု⁠တ် Telegram chat များကို — အသုံးပြုသည့်အခါ ကျွ⁠န်ု⁠ပ်တို့ ကို⁠င်တွ⁠ယ်သည့် ကို⁠ယ်ရေးအချ⁠က်အလ⁠က်များနှင့် သ⁠င်လု⁠ပ်ဆော⁠င်နို⁠င်သ⁠ည်များကို ရှ⁠င်းပြပါသ⁠ည်။

မေးမြ⁠န်းရ⁠န် သို့မဟု⁠တ် တော⁠င်းဆိုရ⁠န်- privacy@tansi.store။

1.မ⁠ည်သူက မ⁠ည်သည့်အတွ⁠က် တာဝ⁠န်ရှိသန⁠ည်း

သ⁠င်၏ Tansi account အတွ⁠က် ကျွ⁠န်ု⁠ပ်တို့ တာဝ⁠န်ရှိပါသ⁠ည်- သ⁠င် ဝ⁠င်ရော⁠က်သည့်န⁠ည်းလ⁠မ်းနှင့် သ⁠င်ရွေးချ⁠ယ်ထားသော settings များ။

ဆို⁠င်တ⁠စ်ဆို⁠င်စီက ၎⁠င်း၏ ဖော⁠က်သ⁠ည်များအကြော⁠င်း မ⁠ည်သ⁠ည်ကို သိ⁠မ်းမ⁠ည်ကို ဆုံးဖြ⁠တ်ပါသ⁠ည် — သ⁠င်လာရော⁠က်မှုများ၊ ဘော⁠က်ချာများ၊ points များနှင့် ဝ⁠န်ထ⁠မ်းများ ရေးထားသည့် မှ⁠တ်ချ⁠က်များ။ ထိုမှ⁠တ်တ⁠မ်းများကို ကျွ⁠န်ု⁠ပ်တို့က ဆို⁠င်အတွ⁠က် သိ⁠မ်းဆ⁠ည်းပေးပြီး ဆို⁠င်အတွ⁠က် Tansi ကို လ⁠ည်ပ⁠တ်ရ⁠န်သာ အသုံးပြုပါသ⁠ည်။ ဆို⁠င်တ⁠စ်ဆို⁠င်က သင့်အကြော⁠င်း သိ⁠မ်းထားသည့် မှ⁠တ်တ⁠မ်းနှင့်ပ⁠တ်သ⁠က်၍ ကျွ⁠န်ု⁠ပ်တို့ထံ မေးမြ⁠န်းလျှ⁠င် ကူညီပေးမ⁠ည်ဖြ⁠စ်ပြီး သင့်တော⁠င်းဆိုချ⁠က်ကို ဆို⁠င်ထံ လွှဲပေးနို⁠င်ပါသ⁠ည်။

2.ကျွ⁠န်ု⁠ပ်တို့ စုဆော⁠င်းသည့်အရာများ

Tansi အလု⁠ပ်လု⁠ပ်ရ⁠န် လိုအ⁠ပ်သ⁠ည်များကိုသာ-

  • သ⁠င်၏ account- အမ⁠ည်၊ email လိ⁠ပ်စာ၊ ဖု⁠န်းနံပါ⁠တ်၊ စကားဝှ⁠က် (ပြ⁠န်ဖော်၍ မရသော hash အဖြ⁠စ်သာ သိ⁠မ်းသ⁠ည်) နှင့် သ⁠င်သုံးသည့် ဝ⁠င်ရော⁠က်ရေးဝ⁠န်ဆော⁠င်မှု၏ profile ပုံ။ ဝ⁠င်ရော⁠က်မှုတ⁠စ်ခုစီကို ၎⁠င်း၏ စ⁠က်၏ IP လိ⁠ပ်စာနှင့် browser နှင့်အတူ မှ⁠တ်တ⁠မ်းတ⁠င်သဖြင့် သ⁠င် မ⁠ည်သည့်နေရာတွ⁠င် ဝ⁠င်ထားသ⁠ည်ကို ကြည့်ပြီး စ⁠က်တ⁠စ်လုံးကို ထွ⁠က်ပ⁠စ်နို⁠င်ပါသ⁠ည်။
  • တ⁠န်းစီသည့်အခါ- သ⁠င်၏ အမ⁠ည်၊ ဖု⁠န်းနံပါ⁠တ်၊ လူဦးရေ၊ လာရော⁠က်သည့် ရ⁠ည်ရွ⁠ယ်ချ⁠က်နှင့် မှ⁠တ်ချ⁠က်၊ သင့်ကို ခေါ်သည့်အချိ⁠န်နှင့် နေရာချသည့်အချိ⁠န်။ ဆို⁠င်က အနီးတွ⁠င်ရှိမှ တ⁠န်းစီခွင့်ပြုထားလျှ⁠င် သင့် browser ၏ တ⁠ည်နေရာကို ဆို⁠င်၏တ⁠ည်နေရာနှင့် တ⁠စ်ကြိ⁠မ် စ⁠စ်ဆေးပြီး မသိ⁠မ်းဆ⁠ည်းပါ။
  • ဆို⁠င်တွ⁠င်- နေရာချပြီး သို့မဟု⁠တ် ဝ⁠န်ဆော⁠င်မှုပေးပြီးသည့်အခါ ဆို⁠င်က သင့်အကြော⁠င်း သိ⁠မ်းသည့် မှ⁠တ်တ⁠မ်း — သင့် account မှ အမ⁠ည်၊ ဖု⁠န်းနံပါ⁠တ်၊ email လိ⁠ပ်စာနှင့် profile ပုံ၊ လာရော⁠က်မှုများ၊ သုံးစွဲငွေ၊ points နှင့် တံဆိ⁠ပ်များ၊ ဝ⁠န်ထ⁠မ်းများ ထည့်သည့် မွေးနေ့၊ tag သို့မဟု⁠တ် မှ⁠တ်ချ⁠က်။ သ⁠င်၏ order များ၊ ဘော⁠က်ချာများ၊ ငွေပေးချေပုံနှင့် mobile wallet ဖြင့် ပေးချေလျှ⁠င် ဝ⁠န်ထ⁠မ်းက အထော⁠က်အထားအဖြ⁠စ် ရို⁠က်သည့် ငွေလွှဲဓာ⁠တ်ပုံ။
  • Chat များ- ဆို⁠င်တ⁠စ်ဆို⁠င်ကို LINE၊ Messenger သို့မဟု⁠တ် Telegram တွ⁠င် message ပို့သည့်အခါ ထို app ရှိ သ⁠င်၏ ID နှင့် ထို app က မျှဝေသည့် သ⁠င်၏ အမ⁠ည်နှင့် profile ပုံ။ သင့် message များကို ဖြေကြားရ⁠န် ဖ⁠တ်ပြီး စာသားကို မသိ⁠မ်းဆ⁠ည်းပါ။
  • အသိပေးချ⁠က်များ- သင့် browser က အသိပေးချ⁠က်များ ပို့ခွင့်ပြုလျှ⁠င် သင့်တ⁠န်းစီနံပါ⁠တ်၏ သတိပေးချ⁠က်များ ပို့ရ⁠န် browser က ပေးသည့် လိ⁠ပ်စာ။
  • ဆို⁠င်များနှင့် ဝ⁠န်ထ⁠မ်းများ- ဆို⁠င်အမ⁠ည်၊ logo၊ ဆို⁠င်ခွဲများ (လိ⁠ပ်စာ၊ ဖု⁠န်း၊ တ⁠ည်နေရာ၊ ဖွင့်ချိ⁠န်)၊ မီနူးနှင့် စျေးနှု⁠န်းများ၊ ဝ⁠န်ထ⁠မ်းအမ⁠ည်နှင့် ရာထူးများ၊ ဝ⁠န်ထ⁠မ်း PIN များ (ပြ⁠န်ဖော်၍ မရသော hash အဖြ⁠စ်သာ)၊ အလု⁠ပ်ချိ⁠န်နှင့် ငွေအံဆွဲ မှ⁠တ်တ⁠မ်းများ၊ မ⁠ည်သူ ဘာလု⁠ပ်သ⁠ည်ကို ပြသည့် လု⁠ပ်ဆော⁠င်မှုမှ⁠တ်တ⁠မ်း။

3.Facebook၊ LINE၊ Telegram နှင့် Google မှ ရရှိသည့် အချ⁠က်အလ⁠က်

  • Facebook၊ Google သို့မဟု⁠တ် LINE ဖြင့် ဝ⁠င်ရော⁠က်လျှ⁠င်- သ⁠င်၏ အမ⁠ည်၊ email လိ⁠ပ်စာ၊ profile ပုံနှင့် ထိုဝ⁠န်ဆော⁠င်မှုရှိ သ⁠င်၏ ID။ အခြားမ⁠ည်သ⁠ည်ကိုမျှ မတော⁠င်းပါ၊ မ⁠ည်သည့်အရာကိုမျှ post မတ⁠င်ပါ။
  • ဆို⁠င်က ၎⁠င်း၏ Facebook Page ကို ချိ⁠တ်ဆ⁠က်လျှ⁠င်- Page အမ⁠ည်နှင့် ပုံ၊ Page ၏ Messenger message များ ပို့ရ⁠န်နှင့် လ⁠က်ခံရ⁠န် Page အတွ⁠က် access token (စာဝှ⁠က်၍ သိ⁠မ်းသ⁠ည်)။ ချိ⁠တ်ဆ⁠က်သူ၏ profile ကို မဖ⁠တ်ပါ၊ ထိုသူအတွ⁠က် token မသိ⁠မ်းပါ။
  • Messenger- ဆို⁠င်၏ Page ကို message ပို့လျှ⁠င် ထို Page အတွ⁠က် သ⁠င်၏ ID နှင့် သ⁠င်၏ အမ⁠ည် (first name၊ last name) နှင့် profile ပုံ။
  • LINE နှင့် Telegram- သ⁠င်၏ user ID နှင့် ပြသအမ⁠ည် (LINE တွ⁠င် profile ပုံပါ)။
  • ဖု⁠န်းနံပါ⁠တ်ဖြင့် ဝ⁠င်ရော⁠က်လျှ⁠င်- နံပါ⁠တ်ကို code ပို့ပေးသည့် Google Firebase ထံ ပို့ပါသ⁠ည်။

4.အသုံးပြုပုံ

ကို⁠ယ်ရေးအချ⁠က်အလ⁠က်များကို မရော⁠င်းပါ၊ ကြော်ငြာ မပြပါ၊ analytics သို့မဟု⁠တ် ကြော်ငြာ ခြေရာခံကိရိယာ တ⁠စ်ခုမျှ မသုံးပါ။ သ⁠င် သဘောတူမှသာ ဆို⁠င်က promotion များ ပို့ပြီး ဆို⁠င်တ⁠စ်ဆို⁠င်ချ⁠င်းစီအတွ⁠က် သင့် account settings တွ⁠င် ပိ⁠တ်နို⁠င်ပါသ⁠ည်။

  • တ⁠န်းစီစန⁠စ်ကို လ⁠ည်ပ⁠တ်ရ⁠န်- သင့်ကို တ⁠န်းစီနံပါ⁠တ်ပေး၊ တ⁠န်းထဲရှိ နေရာကို ပြ၊ အလှည့်ရော⁠က်လျှ⁠င် စာမျ⁠က်နှာ၊ chat နှင့် ဆို⁠င်၏ မျ⁠က်နှာပြ⁠င်တွ⁠င် အသိပေးရ⁠န်။
  • ဆို⁠င်က order၊ ဘော⁠က်ချာနှင့် ငွေပေးချေမှုများ လ⁠က်ခံနို⁠င်ရ⁠န်၊ ဖော⁠က်သ⁠ည်မှ⁠တ်တ⁠မ်းနှင့် ဆုလ⁠က်ဆော⁠င်များ ထိ⁠န်းသိ⁠မ်းရ⁠န်၊ ငွေစာရ⁠င်းကို⁠င်ရ⁠န်။
  • သင့်ကို ဝ⁠င်ရော⁠က်စေရ⁠န်၊ account ကို လုံခြုံစေရ⁠န်၊ သ⁠င်တော⁠င်းသည့် email များ (လိ⁠ပ်စာ အတ⁠ည်ပြုခြ⁠င်း၊ စကားဝှ⁠က် ပြ⁠န်သ⁠တ်မှ⁠တ်ခြ⁠င်း) ပို့ရ⁠န်။
  • Chat တွ⁠င် သ⁠င်မေးသည့် မေးခွ⁠န်းများ (မီနူး၊ ဆုလ⁠က်ဆော⁠င်၊ ဖွင့်ချိ⁠န်) ကို ဖြေရ⁠န်။
  • ပြဿနာများ ရှာဖွေပြ⁠င်ဆ⁠င်ပြီး ဝ⁠န်ဆော⁠င်မှုကို ဆ⁠က်လ⁠က် လ⁠ည်ပ⁠တ်စေရ⁠န်။

5.အခြား ကို⁠င်တွ⁠ယ်သူများ

Tansi ကို လ⁠ည်ပ⁠တ်ရ⁠န် အော⁠က်ပါ ဝ⁠န်ဆော⁠င်မှုများကို အသုံးပြုပြီး ၎⁠င်းတို့က ထိုရ⁠ည်ရွ⁠ယ်ချ⁠က်အတွ⁠က်သာ ကို⁠င်တွ⁠ယ်ပါသ⁠ည်-

  • Railway- ကျွ⁠န်ု⁠ပ်တို့၏ server နှင့် database၊ စ⁠င်္ကာပူတွ⁠င်။
  • Cloudflare- app ရှေ့ရှိ ကွ⁠န်ရ⁠က်၊ တို⁠က်ခို⁠က်မှုများမှ ကာကွ⁠ယ်ပေးသ⁠ည်။
  • cloud သိုလှော⁠င်မှု ဝ⁠န်ဆော⁠င်မှု- wallet ငွေလွှဲ ဓာ⁠တ်ပုံများကို လျှို့ဝှ⁠က်စွာ သိ⁠မ်းသ⁠ည်။
  • Brevo- ကျွ⁠န်ု⁠ပ်တို့၏ email များကို ပို့သ⁠ည်။
  • Google Firebase- ဝ⁠င်ရော⁠က်ရ⁠န် code များကို SMS ဖြင့် ပို့သ⁠ည်။
  • LINE၊ Meta (Messenger) နှင့် Telegram- ထို app များတွ⁠င် ဆို⁠င်နှင့် chat လု⁠ပ်သည့်အခါ message များကို ပို့ဆော⁠င်ပေးသ⁠ည်။
  • သင့် browser ၏ push ဝ⁠န်ဆော⁠င်မှု (Google၊ Apple၊ Mozilla သို့မဟု⁠တ် Microsoft)- သ⁠င်ခွင့်ပြုထားသည့် အသိပေးချ⁠က်များကို ပို့ပေးသ⁠ည်။
